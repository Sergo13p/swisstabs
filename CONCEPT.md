# Концепция v2: TabsBook → «швейцарский нож» для Chrome/Google

Цель: превратить панель в **персональный центр управления** — круче, чем были
iGoogle (закрыт в 2013) и Protopage: современный, с превью, AI-поиском,
синхронизацией и приватностью (всё живёт локально + ваш Google Drive).

## 1. Чем мы отличаемся от iGoogle/Protopage

| | iGoogle / Protopage | TabsBook v2 |
|---|---|---|
| Стартовые страницы | гаджеты | гаджеты (виджеты) |
| Закладки | плоские | дерево + плитки с реальными превью |
| Поиск | только Google | Google + ИИ (Google AI/Perplexity/ChatGPT/Claude) |
| Синхронизация | своя/нет | ваш Google Drive, слияние без конфликтов |
| Приватность | облачные аккаунты | локально, открытый код, без сторонних трекеров |
| Эпоха | 2000-е, десктоп-only | клавиатура-first, тёмная тема, офлайн-кэш |

## 2. Логика интерфейса — три зоны и одно поле ввода

```
┌──────────┬──────────────────────────────────────────────┐
│          │  [ 🔍 Умная строка / палитра  Ctrl+K      ]  │  ← действие
│ Дерево   ├───────────────────────────┬──────────────────┤
│ закладок │  Плитки быстрого доступа  │  Виджеты         │  ← информация
│ (есть)   │  с превью (есть)          │  (правый рейл)   │
│          ├───────────────────────────┴──────────────────┤
│          │  строка фильтра закладок (есть)              │
└──────────┴──────────────────────────────────────────────┘
```

Принципы:

1. **Одно поле — всё под рукой.** Умная строка сама решает, что делать: нашла
   закладку/вкладку — открывает её, нет — ищет в интернете (Google или ИИ).
   Строка фильтра остаётся отдельной для «посмотреть только свои плитки».
2. **Режимы-настроения** (переключатель в шапке, состояние синкается):
   - **Фокус** — только поиск и плитки (сейчасшний вид);
   - **Дашборд** — + виджеты справа;
   - **Компакт** — плотная сетка без превью (для слабых машин).
3. **Клавиатура прежде мыши:** `Ctrl+K` палитра, `/` фильтр, `G` веб-поиск,
   `N` добавить, `Esc` закрыть, `↑↓ Enter` — выбор в палитре.
4. **Ничего не мигает:** панель рендерится из кэша, данные обновляются в фоне
   (паттерн уже применён для превью — расширяем на виджеты).

## 3. Умная строка (омнибокс) — правила ввода

| Ввод | Результат |
|---|---|
| `хлеб` (без совпадений) | Google-поиск (или ИИ, если включён режим ИИ) |
| `хлеб` (совпала закладка/вкладка/история) | под строкой топ-3: `Enter` — открыть, `↓` — выбрать, `Tab` — всё же в Google |
| `g хлеб` | всегда Google |
| `ai хлеб` | всегда ИИ |
| `t назв` | поиск по **открытым** вкладкам (переключиться) |
| `h назв` | история браузера |
| `@drive назв` | поиск файла в Google Drive |
| `2+2*8` | калькулятор → 18 (Enter — скопировать) |
| `15кг в фунты`, `100евро в руб` | конвертер |
| `url` | открыть / «Открыть + копировать» |

Подсказки — Google Suggest (best-effort, без ключей) + собственные источники
(закладки/вкладки) вперёд них.

## 4. Модель виджетов (iGoogle, но правильно)

Каждый виджет — модуль:

```js
{
  id: 'weather',
  title: 'Погода',
  icon: '🌤',
  size: [2, 2],            // в клетках сетки
  refresh: 30 * 60_000,    // период фонового обновления
  permissions: [],         // host/identity scopes, запрашиваемые по требованию
  settings: { city: 'Москва' },   // диалог настроек виджета
  // рендер только из кэша; данные тянет фоновый воркер
}
```

- **Сетка** с перетаскиванием (drag & drop), как в iGoogle/Protopage;
- **Layout и настройки виджетов — часть нашего state** → существующее
  слияние «последняя запись побеждает» синкается без новой работы;
- **Refresh — одним таймером** в service worker (аларм), не таймером на виджет;
  панель получает готовое из `chrome.storage`.

## 5. Каталог виджетов (по сложности)

### Зелёные — без ключей и OAuth (первый эшелон)
| Виджет | Источник |
|---|---|
| 🌤 Погода | Open-Meteo (бесплатно, без ключа) |
| 📰 Новости | RSS/Atom: любые фиды + Google News по теме |
| 📺 Новые видео | RSS загрузок каналов YouTube |
| 🕒 Часы / мировое время / дата | локально |
| 📝 Заметки | свои, синк в Drive (у нас уже есть движок) |
| 💱 Курсы валют | ЦБ РФ XML |
| 📈 Акции/крипто | stooq CSV / Coinbase public API |
| 🎲 «Случайная закладка дня» | наши же данные |
| 🔤 Переводчик | translate.googleapis (best-effort) |

### Жёлтые — нужен OAuth scope (consent screen → новый scope → перелогин)
| Виджет | Scope |
|---|---|
| ✉ Gmail: непрочитанные | `gmail.readonly` |
| 📅 Ближайшие события Google Календаря | `calendar.readonly` |
| ✅ Google Tasks | `tasks.readonly` |
| 📁 Быстрый поиск по Drive | `drive.readonly` (у нас уже `drive.appdata`) |

### Красные — не делаем / заменяем
- **Google Keep** — нет публичного API → вместо него свои Заметки;
- **Лента ВК/телеграма** — сторонние API, приватность;
- **Веб-камера, погода «с веба»** — лишние разрешения.

## 6. «Нож»: вкладки, сессии, инструменты

- **Сессии**: сохранить набор вкладок → восстановить одной кнопкой; авто-имя по
  доминирующей теме; синк через Drive (отдельный файл).
- **Палитра вкладок** (`t`): найти открытую вкладку среди сотен, переключиться.
- **Дедупликатор**: найти/закрыть дубликаты вкладок, «закрыть все вкладки
  домена».
- **«Посушить вкладки»** — `chrome.tabs.discard` (экономия RAM, аналог
  Sleeping Tabs).
- **Открыть папку как вкладки** — из дерева и из плиток-папок.
- **Reading list** — интеграция `chrome.readingList` (официальный API Chrome).
- **QR-код ссылки** — генерация локально (однофайловая JS-библиотека).
- **Скриншот страницы** — та же механика, что превью: «снять и скачать».

## 7. Архитектура: как ложится на существующее

```
state (chrome.storage.local, синк LWW) — схема v2:
{
  version: 2, seeded, updatedAt,
  tiles:    { id: tile },      // есть
  layout:   { mode, columns }, // новое: раскладка и режим
  widgets:  { id: config },    // новое: установки/настройки виджетов
  notes:    { id: note },      // новое (если больно — отдельный Drive-файл)
}
```

- **Слияние уже готово**: `mergeStates` работает по-ключево — новые карты
  подключаются без изменений движка.
- **Фон**: общий `refreshWidgets()` в service worker по аларму; результат — в
  storage; панель слушает `storage.onChanged` (паттерн превью).
- **OAuth**: scopes добавляем в `manifest.oauth2.scopes` поэтапно; каждый
  жёлтый виджет при первом включении просит перелогин (`getAuthToken`).
- **Сеть**: фетч идёт из SW (уже есть `<all_urls>`); кэш с TTL, offline-фоллбэк.

## 8. Дорожная карта

| Этап | Что | Ожидаемый эффект |
|---|---|---|
| **Э1. Палитра** | Ctrl+K: закладки+вкладки+история+веб+ИИ, калькулятор, префиксы | главный «вау-момент», дёшево |
| **Э2. Виджеты** | движок сетки + Погода, Новости(RSS), Часы, Заметки | iGoogle-нотка |
| **Э3. Google** | Gmail, Календарь, Tasks, Drive-поиск | «гугловойность» |
| **Э4. Вкладки** | сессии, палитра вкладок, дедуп, discard, reading list | продуктивность |
| **Э5. Полировка** | режимы, темы, профили (Работа/Личное), QR, скриншот | доведение до ума |

Оценка: Э1 — 1 вечер, Э2 — 2–3 дня, Э3 — 2 дня, Э4 — 2 дня, Э5 — 1–2 дня.

## 9. Риски

1. **Неофициальные Google-эндпоинты** (Suggest, Translate gtx) могут умереть →
   всегда есть запасной путь (без подсказок / без переводчика).
2. **Квота appDataFolder Google Drive** — держим sync-файл компактным; заметки
   при росте — в отдельный файл (движок multi-file — небольшая доработка).
3. **OAuth scope'ы пугают при установке** → просим по требованию, с объяснением.
4. **Service worker умирает по 30 с** → весь фон — через `alarms` (так уже
   сделано), никаких длинных таймеров.
