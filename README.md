# SwissTabs — швейцарский нож для закладок Chrome

> **English:** a Chrome (Manifest V3) new-tab replacement inspired by the classic
> TabsBook: a grid of tiles with **real page previews** (screenshots you collect
> as you browse, with hover cards like Chrome tabs), a live **bookmark tree**,
> one search box for both bookmarks and the web (**Google or AI mode** —
> Google AI Mode / Perplexity / ChatGPT / Claude), and optional **Google Drive
> sync** (conflict-free merge, thumbnails stay local). Setup in
> [README](#установка-без-синхронизации); roadmap in [CONCEPT.md](CONCEPT.md).
> All UI and docs are in Russian — contributions welcome.

Расширение для Chrome (Manifest V3), вдохновлённое классическим TabsBook:

- **Панель быстрого доступа** — открывается вместо новой вкладки (и по клику на иконку в панели): сетка плиток с фавиконами, названиями и адресами.
- **Боковая панель с деревом закладок Chrome** — папки и закладки браузера в виде дерева: сворачивание/разворачивание
  (состояние запоминается), фавиконы, счётчик содержимого, клик открывает вкладку; дерево живое —
  любые изменения закладок в Chrome подтягиваются сразу; можно свернуть панель кнопкой `‹`.
- **Поиск фильтрует и сетку, и дерево** — дерево при поиске автоматически разворачивает совпавшие ветки.
- **Поиск в интернете** — большая строка над поиском по закладкам: обычный **Google** или режим **✨ ИИ**
  (**Google AI Mode** по умолчанию; также Perplexity / ChatGPT / Claude — выбор сохраняется).
  Enter — открыть результат в новой вкладке, клавиша `G` — фокус в строку.
- **Превью страниц** — плитки показывают настоящие скриншоты сайтов (как в Vivaldi), а при наведении
  всплывает карточка с большим превью и заголовком — как при наведении на вкладку Chrome.
- **Клик по папке в дереве** открывает её содержимое справа в основной области: хлебные крошки для перехода
  к родительским папкам, `✕` — назад к плиткам; внутри папки подпапки — плитки-папки (клик — войти внутрь),
  закладки — обычные плитки, у каждой кнопка `＋` «добавить в панель быстрого доступа».
- **Импорт закладок Chrome** — при первом запуске все ваши http/https-закладки автоматически переносятся в панель.
- **Добавление / редактирование / удаление / перетаскивание** плиток прямо на панели.
- **Поиск** по названию и адресу (клавиша `/`), быстрое добавление — клавиша `N`.
- **Контекстное меню** — «Добавить в панель закладок» по правой кнопке на странице или ссылке.
- **Синхронизация с Google Drive** — состояние панели хранится в приватном файле вашего Google-аккаунта
  (`appDataFolder`) и сливается между всеми компьютерами, где установлено расширение.

## Как работают превью страниц

Расширение не может открыть произвольный адрес в фоне и снять его — поэтому превью собираются
**при посещении сайтов**:

1. Кнопка **👁 Превью** в шапке показывает состояние сбора: выключено / включено / количество
   собранной миниатюр, а в подсказке — последний снимок или последняя ошибка.
   Доступ к сайтам объявлен в `host_permissions` манифеста: при загрузке расширения в режиме
   разработчика Chrome выдаёт его автоматически, без диалогов. Если доступ отозван — включите его:
   `chrome://extensions` → SwissTabs → Подробности → Доступ к сайтам → «Разрешить на всех сайтах».
   (Для публикации в Chrome Web Store лучше перенести `<all_urls>` обратно в
   `optional_host_permissions` и запрашивать по клику.)
2. Когда страница загрузилась и окно в фокусе, расширение снимает видимую область
   (`captureVisibleTab`), уменьшает её до 480px в offscreen-документе и кладёт в хранилище.
3. Плитка показывает скриншот (16:10, сверху), при наведении — большая карточка как на вкладках.
4. Снимок обновляется не чаще раза в сутки; старые (последние 600) подчищаются автоматически.

То есть над готовым превью появляется после того, как вы один раз зашли на сайт. Скриншоты
хранятся **только локально** и в Google Drive не отправляются.

## Превью не появляются?

Порядок проверки:

1. **Кнопка 👁 в шапке** — она показывает состояние:
   - `👁 Превью` (неактивна) — доступа к сайтам нет; клик попытается запросить, иначе включите его:
     `chrome://extensions` → Подробности → Доступ к сайтам → «Разрешить на всех сайтах».
   - `👁 Превью: вкл` — разрешение есть, но миниатюр ещё 0: откройте нужные сайты,
     снимок делается через ~2 секунды после загрузки страницы, пока окно в фокусе.
   - `👁 Превью: N` — сбор идёт, N миниатюр уже собрано.
2. **Наведите на кнопку** — в подсказке последний успешный снимок (адрес и время)
   или последняя ошибка (например, отказ в доступе).
3. Панель перерисовывает плитки сразу — если сайт уже посещён, но плитка старая,
   откройте панель заново.
4. Подробный журнал: `chrome://extensions` → «Сервис-воркер» (Console) → ищите `[SwissTabs]`.

Типовые причины: разрешение выдано только до перезагрузки расширения (нажмите ⟳ —
и кнопка покажет, снято ли разрешение); сайт открыто в фоновой вкладке или окно Chrome
не в фокусе; страница ещё грузилась в момент проверки.

## Установка (без синхронизации)

1. *(Опционально, для синхронизации между компьютерами)* выполните `./scripts/apply-key.sh` —
   подробности в разделе про [синхронизацию](#2-oauth-client-id).
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. **Загрузить распакованное расширение** → выберите папку `swisstabs`.
5. Откройте новую вкладку — увидите панель.

Без настройки Google всё работает, кроме синхронизации (на панели будет подсказка).

## Настройка синхронизации с Google

Синхронизация использует Google Drive API и OAuth-вход в вашу учётную запись Google.

### 1. Проект в Google Cloud

1. Откройте [console.cloud.google.com](https://console.cloud.google.com) и создайте проект.
2. **APIs & Services → Library** → найдите **Google Drive API** → **Enable**.
3. **APIs & Services → OAuth consent screen**:
   - User Type: **External**, заполните название и email поддержки;
   - на шаге **Scopes** добавьте `https://www.googleapis.com/auth/drive.appdata`
     (если нет в списке — перейдите по ссылке «Аутентификация → Настройки → Пользователи с доступом»
     и добавьте свой Gmail в **Test users**);
   - сохраните.

### 2. OAuth client ID

1. **APIs & Services → Credentials → Create credentials → OAuth client ID**.
2. Application type: **Chrome Extension** (если такого типа нет — **Web Application** не подойдёт,
   выбирайте именно тип для расширений/приложений Chrome).
3. **Item ID**: ID вашего расширения из `chrome://extensions`
   (например, `abcdefghijklmnopabcdefghijklmnop` — 32 символа без дефисов).
4. Скопируйте выданный **Client ID** вида `...apps.googleusercontent.com`.

> ℹ️ **Стабильный ID расширения.** По умолчанию Chrome выводит ID из пути к папке —
> при копировании на другой компьютер он изменится, а Google привязывает Client ID
> именно к ID. Чтобы ID был одинаков везде, выполните **до загрузки расширения**:
>
> ```bash
> ./scripts/apply-key.sh
> ```
>
> Скрипт сгенерирует (или переиспользует) приватный ключ в `~/.config/swisstabs/key.pem`
> и вставит публичную часть в `manifest.json` — ID станет постоянным (будет напечатан
> на экране). **Не держите `.pem` внутри папки расширения** — Chrome запрещает загружать
> такие расширения и показывает предупреждение «это неприемлемо». Без скрипта всё тоже
> работает, просто ID будет «своим» у каждого компьютера, и синхронизация потребует
> отдельного Client ID для каждого (добавляется в том же Google Cloud проекте как
> ещё одна OAuth-запись).

### 3. Вставьте Client ID в manifest.json

```json
"oauth2": {
  "client_id": "ВАШ_КОД.apps.googleusercontent.com",
  "scopes": ["https://www.googleapis.com/auth/drive.appdata"]
}
```

Перезагрузите расширение на странице `chrome://extensions` (кнопка ⟳).

### 4. Первый вход

1. Откройте панель → кнопка **«Синхронизация»**.
2. Браузер откроет окно входа Google — выберите аккаунт и разрешите доступ.
3. Данные запишутся в файл `swisstabs-sync.json` в приватном хранилище приложения Drive
   (виден только расширению, не появится в «Моём диске»).

Дальше синхронизация идёт автоматически: при каждой правке (с задержкой в несколько секунд)
и раз в 15 минут фоном.

### Режим «Testing»

Пока приложение не опубликовано, Google считает его тестовым: refresh-токены пользователей
истекают примерно через 7 дней. Это не значит, что данные пропадут — просто раз в неделю
потребуется заново нажать «Синхронизация» и подтвердить вход. Для личного использования
обычно хватает «Testing», для постоянной работы — опубликуйте приложение (**Publish app**)
на экране OAuth consent screen.

## Как работает слияние

- Каждая плитка хранит свой `updatedAt`; при встрече двух версий побеждает более новая запись.
- Удалённые плитки помечаются флагом `deleted` (надгробие), поэтому удаление тоже
  разъезжается по всем устройствам, а не «воскресает» при следующей синхронизации.
- Конфликтов «кто сильнее» у обычного использования не бывает: правки на разных машинах
  просто объединяются.

## Структура проекта

```
swisstabs/
├── manifest.json      # манифест MV3 (+ oauth2 client_id)
├── background.js      # воркер: импорт, меню, синхронизация, снятие превью
├── panel.html/css/js  # сама панель (новая вкладка)
├── offscreen.html/js  # сжатие скриншотов в миниатюры (canvas)
├── lib/store.js       # состояние плиток, импорт закладок, слияние версий
├── lib/sync.js        # OAuth + Google Drive (appDataFolder)
├── lib/thumbs.js      # хранение и LRU-обрезка превью
├── lib/util.js        # ключ превью, URL поиска (Google/ИИ)
├── scripts/apply-key.sh  # фиксация ID расширения (для синхронизации)
├── icons/             # иконки
├── make_icons.py      # генератор иконок (опционально)
├── CONCEPT.md         # концепция развития: виджеты, омнибокс, Google-модули
└── LICENSE            # MIT
```

## Клавиши и действия

| Действие | Как |
|---|---|
| Поиск по закладкам | `/` |
| Поиск в интернете (Google/ИИ) | `G`, затем Enter |
| Добавить закладку | `N` или кнопка «+ Добавить» |
| Изменить / удалить | навести на плитку → ✎ / ✕ |
| Изменить порядок | перетащить плитку мышью |
| Свернуть боковую панель | кнопка `‹` в её шапке |
| Добавить открытую страницу | ПКМ → «Добавить в панель закладок» |
